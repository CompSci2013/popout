# Bug 002: First Launch Missing Styles

## Problem
On the very first time a popout is opened after a full page refresh, the component styles (generated by Angular's ViewEncapsulation) might not yet be present in the parent window's `<head>`. If `copyStylesToPopout` is called before Angular has finished injecting these styles into the parent, the popout window will appear unstyled.

## Fix
The `PopoutManagerService` now calls `copyStylesToPopout` **after** the portal has been attached to the outlet. This ensures that Angular has had a chance to generate and inject the component-specific styles into the parent document, making them available for cloning.

```typescript
const componentRef = outlet.attach(portal);
// Styles are now guaranteed to be in the parent's <head>
this.copyStylesToPopout(popoutWindow);
```
